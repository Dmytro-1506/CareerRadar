# CareerRadar

Search for nearby companies, discover career pages, collect application contacts, manage job applications, and track your application progress.

## Features

✅ Search companies by keyword
✅ Discover career pages
✅ Find application email addresses
✅ Track submitted applications
✅ Prevent duplicate applications

🚧 Radius search
🚧 Interactive map
🚧 AI company ranking
🚧 Automatic email sending

## Tech Stack

Frontend

• Vite

Backend

• Express

Database

Search Engine

## Getting Started

1. Clone the repository
   git clone https://github.com/Dmytro-1506/CareerRadar.git
   cd CareerRadar
2. Create environment files
   Copy:

   .env.example
   → .env

   backend/.env.example
   → backend/.env

   and update the values if necessary.

3. Install dependencies
   npm install
4. Start the application
   docker compose up --build
5. Open
   Frontend
   http://localhost:5173

   Backend
   http://localhost:3000
