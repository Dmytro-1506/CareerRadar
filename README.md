# CareerRadar

Find nearby companies, discover career pages, collect application contacts, manage job applications, and track your application progress.

## Features

- Search companies by city
- Radius search (coming soon)
- Career page detection
- Application email discovery
- Company rating
- Application tracking
- Duplicate application detection

## Tech Stack

Frontend
- React
- TypeScript

Backend
- Node.js
- Express

Database
- PostgreSQL

Search
- SearXNG

Containers
- Docker
